# Afbeeldingen voor werkvormen

Zet hier per werkvorm één afbeelding. De **bestandsnaam is de titel van de werkvorm**
(hoofd-/kleine letters maakt niet uit). De app koppelt de afbeelding automatisch aan
de juiste werkvorm; is er (nog) geen afbeelding, dan toont de app de categorie-illustratie.

- Ondersteunde formaten: `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.svg`
- Aanbevolen: liggend, ongeveer 800 × 400 px

Voorbeelden:

- `TRIZ.jpg`
- `1-2-4-all.png`
- `impromptu-networking.jpg`

Titels met bijzondere tekens (`/`, `?`, enz.) kunnen niet als bestandsnaam.
Gebruik dan de vereenvoudigde naam, bijvoorbeeld:

- "Impact/Effort-matrix" → `impact-effort-matrix.jpg`
- "Wat kies jij?" → `wat-kies-jij.jpg`
- "What, So What, Now What? (W³)" → `what-so-what-now-what-w3.jpg`
